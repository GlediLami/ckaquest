# 💡 HINT 3: Complete Solution

## Add Toleration to Pod

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: regular-app
  namespace: taints-tolerations
spec:
  nodeSelector:
    kubernetes.io/hostname: ckaquest-worker   # keep this
  containers:
  - name: app
    image: nginx:1.27
  tolerations:  # ✅ Add this!
  - key: "dedicated"  # ✅ Matches taint key
    operator: "Equal"
    value: "gpu"  # ✅ Matches taint value
    effect: "NoSchedule"  # ✅ Matches taint effect
```

## Alternative: Tolerate Any Value

```yaml
tolerations:
- key: "dedicated"
  operator: "Exists"  # Any value
  effect: "NoSchedule"
```

## Apply and Verify

```bash
# Tolerations cannot be added to a running pod. Recreate it:
kubectl get pod regular-app -n taints-tolerations -o yaml > pod.yaml   # add the tolerations block
kubectl replace --force -f pod.yaml

# Verify
kubectl get pod regular-app -n taints-tolerations
# Should be Running

# Run validation
# then press check in the game
```

## Key Points

1. **Taint = repel** pods
2. **Toleration = allow** scheduling
3. All parts must match: key, value, effect
4. operator: "Equal" (exact) or "Exists" (any value)
